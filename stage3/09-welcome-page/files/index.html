Your AirCast Pi is ready

Reachable on your network as aircast.local

Online — finish the steps below to go live

1 Secure the Pi

Default login is pi / raspberry. Change it before exposing SSH.

ssh pi@aircast.local
passwd

2 Join your Tailscale network

Gives a secure path to this Pi from anywhere — no port forwarding.

sudo tailscale up
sudo tailscale set --operator=$USER

3 Connect a camera

Wire an RTSP/IP camera to the wired port, then view it from any player.

vlc rtsp://192.168.8.4:554/stream1

4 Ground station telemetry

Plug in your ArduPilot/PX4 flight controller — telemetry auto-starts. Point a GCS here:

udp server :14550  (mavp2p)

5 Add cellular

Plug in a USB 4G/LTE modem. It auto-detects the carrier APN and connects.

mmcli -L      # list detected modems

6 Wi-Fi (optional)

The radio is unblocked and ready. Join a network with:

nmcli device wifi connect "SSID" password "PASS"
Heads up: MAVLink on port 14550 is unauthenticated. Keep it on your private LAN/Tailscale — never forward it to the public internet.
